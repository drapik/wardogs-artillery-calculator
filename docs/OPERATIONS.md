# Развёртывание

## docker-mam

- Стек: `/opt/wardogs-jarvis`, Compose project `wardogs-jarvis`.
- Адрес панели: `https://jarvis.dixel.store` через существующий Traefik и сеть `proxy`.
- Собственная сеть: `172.16.30.0/28`; задана явно, потому что стандартный Docker address pool на хосте исчерпан. На момент установки пересечений с маршрутами и Docker-сетями нет.
- Данные: volume `wardogs-jarvis_data`, только `state.json` с координатами и настройками.
- Секреты: `.env`, права 600. В Git не добавляются. `.env.local` используется только для локальной проверки.
- Контейнеры: `wardogs-jarvis-app-1` и `wardogs-jarvis-piper-1`. Ресурсы ограничены Compose. Piper доступен только во внутренней сети.
- GigaAM: существующий сервис docker-mam на порту 8765, без изменения его настроек.

```sh
cd /opt/wardogs-jarvis
docker compose ps
docker compose logs --tail 100 app piper
curl -fsS https://jarvis.dixel.store/healthz
```

`/healthz` подтверждает HTTP-сервис и отдельно сообщает состояние Discord. `not_configured` означает, что ещё не заполнены токен и ID сервера. Готовность ASR/TTS видна внизу авторизованной панели.

## Discord — проверка 4 ноября 2026

Приложение и бот переименованы в «Прапорщик Джарвис». Токен установлен только в локальном и серверном `.env`; в Git его нет. Включён Message Content Intent и `DISCORD_MESSAGE_CONTENT=true`, поэтому работают slash-команды и обычное обращение «Джарвис» в чате. Ограничение на один сервер задаётся через `.env`.

Проверены регистрация `/jarvis` и `/джарвис`, вход в живой голосовой канал, получение человеческой речи через Discord и голосовой ответ (подтверждён пользователем). После замечания к длинной озвучке справка перенесена в текстовый чат вызова; текстовая команда «Джарвис, помощь» реально доставила памятку. Piper замедлен: `length_scale=1.20`. Полный сценарий с человеческими координатами и сменой участников остаётся отдельной приёмочной проверкой.

При голосовой команде «помощь» бот останавливает текущую речь, отправляет список в текстовый канал вызова и произносит только подтверждение. Если отправка не удалась, сообщает об ошибке и не зачитывает список. Справка по slash-команде видна только её автору. В аудиоочереди распознавание не ждёт завершения воспроизведения, чтобы команда «стоп» могла прервать речь.

## Обновление

Скопировать исходники, сохранив серверный `.env`; выполнить `docker compose build app && docker compose up -d app`. Piper пересобирать только при изменении его сервиса. После изменения `.env` нужен `docker compose up -d --force-recreate app`.

Для отката перед обновлением закрепить текущие image ID отдельным тегом, затем подставить его в Compose. Не удалять volume при обычном обновлении.

## Приёмочная проверка

1. HTTPS и два healthy контейнера.
2. Без cookie `/api/state` отвечает 401; с личной ссылкой панель работает.
3. Орудие 45/32, цель 48/36, миномёт → 500 м, 36,87°, 461 мил.
4. «Озвучить» возвращает WAV от Piper, ручной и текстовый ввод синхронизированы.
5. Реальный звонок Discord: /jarvis, слово обращения, отдельные пары координат, траектория САУ, смена участников, стоп, уход.

В тестовом прогоне Piper → GigaAM проверены слово обращения и траектория. GigaAM иногда искажает обозначения осей: повторный X или g во второй позиции исправляется только у законченной числовой пары. При потере второго числа команда отклоняется целиком, пользователь получает просьбу повторить. Успешная синтетическая проверка не заменяет человеческую речь и проверку Discord/DAVE.
